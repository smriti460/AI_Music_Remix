# 🎵 AI Music Remix & Mood Generator

## Overview
AI Music Remix & Mood Generator is a Streamlit-based web application that allows users to upload songs and generate mood-based remixes.

## Features
- Upload MP3/WAV songs
- Play uploaded audio
- Select mood:
  - Happy 😊
  - Sad 😔
  - Energetic 🔥
  - Relaxing 🌙
- Generate remixed audio
- Download remixed song

## Technologies Used
- Python
- Streamlit
- Pydub
- FFmpeg

## Project Structure
AI_Music_Remix/
├── app.py
├── remix.py
├── database.py
├── requirements.txt
├── remixed/

## Installation

pip install -r requirements.txt

## Run

streamlit run app.py
